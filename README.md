# Minishell

Mini-interpréteur de commandes en C. Le projet reproduit les mécanismes de base d’un shell : lecture et analyse d’une ligne, exécution, redirections et pipes.

## Compilation et lancement

    make
    ./minishell

Les fonctionnalités et builtins pris en charge sont définis par le code du projet.
